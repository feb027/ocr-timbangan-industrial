## 🏆 JUDUL REKOMENDASI UTAMA

```
Metode : OCR Deep Learning (CNN/CRNN) + koreksi semantik format berat
Tujuan : menutup kesenjangan (gap) akurasi data sintetis → nyata (target ≥95%)
Obyek  : display timbangan industrial (7-segment/LED)
```

### 🇬🇧 English
> **"Deep-Learning OCR with Weight-Format Semantic Correction for Automatic Reading of Industrial Scale Displays: Bridging the Synthetic-to-Real Gap"**

```
Method : Deep-learning OCR + weight-format semantic correction
Goal   : bridge the synthetic→real accuracy gap (target ≥95%)
Object : industrial weighing-scale displays (7-segment/LED)
```

### Kenapa judul ini kuat
1. **Sesuai kaidah slide** — mengandung metode + tujuan + obyek, deskriptif, ≈12 kata (ID).
2. **Spesifik, bukan generik** — "timbangan industri" (bukan "display LCD" umum) dan "koreksi semantik format berat" adalah *distinctive feature*.
3. **Menangkap 2 klaim orisinal dari literatur:**
   - *Desimal/nilai berat harus eksak* → koreksi semantik format-berat (kg, indikator stabil, titik desimal). Dikuatkan oleh **Li & Bai, *Symmetry* 2026** (desimal hilang = error 100×).
   - *Sim-to-real gap* → strategi bridge. Dikuatkan oleh SLR **Array 2026** (controlled-accuracy ≠ field-accuracy) & **Lightweight single-pass 2023** (sintetik 100% → nyata 92%).
4. **Menarik & kuat untuk reviewer** — masalah nyata yang jarang disentuh (timbangan ≠ meter utilitas), gap jelas, solusi konkret.
